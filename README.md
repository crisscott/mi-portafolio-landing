# Mi Portafolio

Landing page personal construida con Next.js 15, React 19 y Tailwind CSS. Incluye secciones de inicio, sobre mí, proyectos y contacto para mostrar mi experiencia profesional y formas de comunicación.

## Scripts

- `npm run dev` – inicia el entorno de desarrollo.
- `npm run build` – genera la versión de producción.
- `npm start` – arranca la aplicación compilada.
- `npm run lint` – ejecuta ESLint sobre el código.
- `npm test` – ejecuta las pruebas con el runner nativo de Node.
